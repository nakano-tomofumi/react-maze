# Repository safety

このリポジトリは公開される前提で扱う。

## コミットしてはいけない情報

次の情報をコード、設定、ログ、ドキュメント、スクリーンショット、生成物などへ含めない。

- 機密情報
- 個人情報
- 認証情報
- API キーやトークン
- Cookie
- 内部 URL
- ローカル環境固有の絶対パス

サンプル値が必要な場合は、実在の値ではなく `example.com`、`YOUR_API_KEY`、`<placeholder>` などのダミー値を使用する。

## ファイル追加時の確認

ログ、設定ファイル、スクリーンショット、生成物を追加または引用する前に、公開して問題ない内容か確認する。

依存関係やビルド成果物を追加する場合は、不要な大容量ファイル、環境依存ファイル、秘密情報が含まれていないか確認する。
